# 面板数据体检清单

跑完描述统计后，必须逐项检查并把结论告诉用户。这些是回归前不修就会出事的问题。

## 1. 面板结构

- **唯一键检查**：`df.duplicated(subset=[公司代码, 年份]).sum()` 应为 0。
  不为 0 说明有重复观测，回归标准误不可信。
- **公司数、年份跨度**：判断样本是否是平衡面板，以及是否需要控制年份固定效应。

## 2. 完全重复的变量对

两列逐行完全相等（`df[a].equals(df[b])`），同时进回归会导致设计矩阵奇异，
软件会自动剔除其中一个或者系数算不出来。

实测案例：`Mfee ≡ AgC1_1`、`Occupy ≡ AgC2`（59241 条逐行一致）。
表现为 VIF = inf。

**处理**：二选一，不要都放。

## 3. 量纲混杂（最常见、最致命）

比率型变量（负债率、存货占比、现金流比率…）正常在 0~1 之间。
如果出现 7.8、39.17 这种值，通常是「7.8% 写成了 7.8 而不是 0.078」。

**判断标准**：
- 中位数在 0~0.3，最大值几十 → 高度怀疑混杂
- 按年份分组看：某几年突然全 >1、其他年份完全没有 → 基本是口径变过

**处理**：只对 >1 的那部分除以 100，**不要整列除**（会把本来对的观测改错）。
改之前先跟数据商核对定义。

**两种不算错误的情况**：
- 整列都是百分数口径（如独立董事占比 33.33 表示 33.33%）——单位统一，
  只是尺度不同，回归时按「1 个百分点」解释系数即可，不用改数据。
- 本来就可以 >1 的比值（如资产总计/营业收入）——分子分母不是包含关系，正常。
  例子：某数据里 Cap2 有 87.5% 的观测 >1，属于这种情况。

**后果**：不处理的话均值会被抬高数倍。实测案例：Mfee 中位数 0.0718，
被 3.3% 的百分数污染后均值拉到 0.352，是中位数的 5 倍。

## 4. 共线性（VIF）

VIF > 10 为严重共线。VIF = inf 表示存在完全线性相关（通常是第 2 条的重复列）。

实测案例：Top5 = 48.06、Top10 = 39.36、Top1 = 13.37，
且 Top5 与 Top10 相关系数 0.9713。**这三个最多选两个进回归**。

VIF 计算（不依赖 statsmodels，手算即可）：

```python
# 对每个变量，用其余变量做 OLS 回归，取 R²
# VIF = 1 / (1 - R²)
```

## 5. 常数列

唯一值 ≤ 1 的变量（如"是否ST"全为 0）没有信息量，不能进回归。
但它本身可能是有用的信息：全为 0 恰好证明样本确实做过 ST 剔除。

## 6. 缩尾是否真的做过

文件名写着"已缩尾"不等于真的缩尾过。看偏度和峰度：

- 1%/99% 缩尾后，偏度一般应降到 2 以内
- 实测案例：Growth 偏度 2.92、TobinQ 3.48、Employ 4.66（员工数没取对数）
  ——说明缩尾做得不干净，建议自己再跑一遍

## 7. 报告给用户的模板

不要只交表格，要点名问题：

```
1. 【必须处理】X 与 Y 数值完全相同，同时进回归会导致矩阵奇异
2. 【必须处理】Z 有 N 条（x%）大于 1，中位数 a 但最大值 b，疑似量纲混杂
3. 【注意】A/B/C 的 VIF 为 …，最多选两个
4. 【提醒】文件名说已缩尾，但 X 偏度仍为 …，建议复核
```
