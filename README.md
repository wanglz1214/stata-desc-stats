# 上市公司面板数据描述性统计流水线

从 Stata 的 `.dta` 面板数据一键生成论文用的全套描述统计结果，最后产出**中文三线表 Word 文档**。

面向没有 Python 基础的使用者：脚本每一步都写了【在干嘛】【原理】两段中文注释。

---

## 一、最快上手（两条命令）

假设你的数据在 `D:\人工智能\xxx.dta`。

```bash
# 1) 跑统计，结果自动落到 数据同级的「输出结果」文件夹
python skill/scripts/stata_desc_pipeline.py "D:/人工智能/xxx.dta"

# 2) 把统计表转成 Word 三线表
python skill/scripts/make_three_line_docx.py ^
  -i "输出结果/02_描述统计_论文格式.csv" ^
  -o "输出结果/主要变量描述性统计.docx" ^
  --title "主要变量描述性统计" ^
  --note "注：样本为……连续变量均经 1% 和 99% 分位缩尾处理。"
```

Windows 上 `python` 若不在 PATH 里，用绝对路径：

```
C:\Users\14568\.workbuddy\binaries\python\versions\3.13.12\python.exe
```

## 四、主流水线参数

```bash
python skill/scripts/stata_desc_pipeline.py 数据.dta [选项]
```

| 参数 | 说明 |
|---|---|
| `--out 目录` | 输出目录，默认「数据同级/输出结果」 |
| `--id stkcd` | 公司代码列名，不传会自动识别 |
| `--year year` | 年份列名，不传会自动识别 |
| `--core Size Lev ROA` | 指定画哪些变量的图，默认取缺失最少的 9 个 |

## 五、会产出什么

| 文件 | 内容 |
|---|---|
| `01_变量清单.csv` | 每个变量的类型、缺失率、唯一值数、中文标签 |
| `01_重复检查.txt` | 公司-年度是否重复、公司数、年份跨度 |
| `02_描述统计.xlsx` | 描述统计 / 论文格式 / 虚拟变量频数 / 分年度均值 / 量纲警报 |
| `02_描述统计_论文格式.csv` | **三线表的输入**，7 列中文表头 |
| `03_相关系数矩阵.xlsx` | Pearson、Spearman、长表带显著性星号、VIF |
| `04_图1~3.png` | 变量分布直方图、相关系数热力图、年度趋势图 |

## 七、本次数据体检发现的问题（回归前必须处理）

数据源：`上市公司 控制变量_剔除金融剔除ST或PT已缩尾.dta`，59241 条 × 5271 家公司 × 2001—2024 年。

1. **两对变量数值完全相同**：`Mfee ≡ AgC1_1`、`Occupy ≡ AgC2`（逐行一致，VIF = inf）。
   同时进回归会导致矩阵奇异，二选一。
2. **管理费用率量纲混杂**：`Mfee` 有 1927 条（3.3%）大于 1，最大 39.17，中位数仅 0.0718。
   典型「7.8% 写成 7.8」。对 >1 的部分除以 100 即可，**不要整列除**。
3. **股权集中度严重共线**：Top5 VIF = 48.06、Top10 = 39.36、Top1 = 13.37，
   且 Top5 与 Top10 相关系数 0.9713。三者最多选两个。
4. **缩尾建议复核**：文件名说已缩尾，但 Growth 偏度 2.92、TobinQ 3.48、Employ 4.66，
   1%/99% 缩尾后一般不该剩这么高。

其他口径提醒：`Indep`、`Mshare` 是百分数（33.33 表示 33.33%），
与 `Lev`（0.425）不是同一套尺度；`Top1` 组在 2001—2002 年全缺，
用到它们的回归会自动少两年；`是否发生ST` 全为 0，恰好证明样本确实剔过 ST。
